# group-whisper-link Wiki

Temporary, end-to-end encrypted group chat for up to six people (host plus five guests), in the browser,
on GitHub Pages. No server, no account, nothing stored. The two-person version is whisper-link.

- [Architecture and Design Rationale](Architecture-and-Design-Rationale)
- [Codebase Map](Codebase-Map)

Use the root README for how to run a group chat and for its limits (IP addresses are visible to other members,
there is no relay, and group codes must be compared on a call or in person).
