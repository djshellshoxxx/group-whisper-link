group-whisper-link

end-to-end encrypted group chat. up to 6 nodes. no server. no account. nothing stored.

This browser can't run group-whisper-link. It needs WebRTC and the Web Crypto API, and the page must be served over HTTPS.

Start or join a group chat

The person who creates the group is the host. Everyone else swaps two short codes with the host (by email, text, or any messenger) and joins. Messages are end-to-end encrypted, so the host can't read them either.

Group lobby

Click Add a person for each person you want to invite (up to 5). Send each person their own invite code, and paste the reply code they send back. When everyone has joined, click Start chat. No one can join after that.
